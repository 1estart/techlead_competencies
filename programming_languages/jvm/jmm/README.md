# JMM

Цель этого каталога — показать базовые идеи Java Memory Model на примерах.

## Темы

1. **Атомарность**
   - `counter++` не является атомарной операцией;
   - несколько потоков могут потерять обновления.

2. **Исправление через атомики**
   - `AtomicInteger` делает increment атомарным.

3. **Видимость и публикация**
   - `volatile` гарантирует видимость записи и задаёт happens-before отношение.

## Требования

- JDK 17+;
- желательно Java 21 LTS.
